黑豆芽 Agent - 论文排版工具 MVP 功能与交互概览 (V1)
目标用户：本科生、研究生、医生（非技术背景，注重效率与专业准确度）
核心场景：毕业论文、SCI 论文、项目申请书的自动化排版与智能调整。
设计原则：极简输入、过程透明、对比直观、内容安全。
1. 统一输入与引导区 (Input & Guide)
这是用户进入平台后的第一触点，设计需极其“傻瓜化”。
●	文档/文本极简输入：
○	支持拖拽上传多格式文件（核心兼容 .docx、.pdf）。
○	支持直接粘贴文本。
●	目标模板前置选择：
○	在输入的同时，提供清晰的模板选择器（如：“某大学硕博毕业论文模板”、“Nature 期刊 Author Guidelines”）。
●	快捷指令胶囊按钮 (Action Chips) 【重要交互优化】：
○	放弃极客向的 / 唤醒指令。
○	在对话输入框上方/内部，常驻提供类似豆包的快捷按钮，例如：✨ 一键全文排版、📊 提取并美化图表、📑 规范化参考文献、📝 检查摘要结构。
○	用户点击按钮即可自动填充 Prompt 并触发任务。
●	无感知的模型路由：
○	系统内部按需调度大模型，UI 层面向小白用户隐藏复杂的模型选择界面，降低认知负荷。
2. 思考流与打断机制 (Thinking & Interrupt)
解决用户“不知 AI 在干嘛”、“怕 AI 乱改”的失控感。
●	人类可读的实时进度 (Agent 事件流映射)：
○	将后端的事件流转换为清晰的 UI 提示，例如展示：“🔍 正在分析各个章节层级...” -> “📐 正在应用某某期刊段落间距...” -> “✅ 排版完成”。
●	全局高危操作的“反向确认” (Human-in-the-loop)：
○	当 Agent 判断需要大范围重组文档（如批量调整所有参考文献的角标次序）时，在交互区弹出确认卡片，用户点击“同意”后才执行。
●	随时打断与追加意图：
○	用户可以在 AI 处理过程中点击“停止”，并在当前上下文中补充新的口语化要求（例如：“等一下，正文里不要用黑体”）。
4. 导出与下载服务 (Export)
保障长文档处理的可用性与最终交付。
●	异步后台生成机制：
○	针对几十页的毕业论文，排版和渲染 .docx 需要时间。前端需提供友好的后台任务列表或全局进度环，完成后通过系统通知提醒用户。
●	多格式精准导出：
○	用户可自由选择导出为 .docx（最核心刚需，保证能在本地 Word 中继续无缝编辑）、.pdf（用于直接提交/打印）或 .md。
